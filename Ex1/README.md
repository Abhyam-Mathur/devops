Experiment 1: Compare Virtual Machine with Container

Objective: To compare traditional Virtual Machines with Containers by deploying the same application (Nginx web server) and analyzing performance, resource usage, and deployment complexity.

Technologies Used:

VirtualBox

Vagrant

Ubuntu 22.04 (Jammy)

Docker

Nginx

Key Learnings:

Difference between hypervisor-based and container-based virtualization

VM lifecycle using Vagrant

Container lifecycle using Docker

Port mapping and networking in containers
